# StudyPulse 全 AI 模式设计

交付入口：[`../ai-mode-preview.html`](../ai-mode-preview.html)。HTML 内含全部 CSS、JavaScript 和 SVG，可直接离线打开，无需安装依赖。此目录保存设计说明、视觉证据和检查记录，不是页面运行依赖。

## 任务与方向

为 StudyPulse 的全 AI 模式设计独立对话空间。主要任务是发起学习相关对话、查看学习数据、引用当前数据提问，以及继续历史对话。此次仅交付 HTML 设计原型，不修改 SwiftUI、数据模型或现有应用入口。

方向来自用户提供的 Claude iPhone App 截图：`IMG_9567.PNG`、`IMG_9568.PNG`。借鉴温白色表面、大面积留白、细描边圆形工具按钮、浮在底部的输入框，以及侧栏展开时主页面整体右移的空间关系。品牌保留 StudyPulse，主标记使用新绘制的细线幼苗，关联产品已有的植物养成语境。没有复制 Claude 标志。

视觉重点有两处：安静的新对话开场；数据与对话之间的一步衔接。赭陶色只用于品牌标记，鼠尾草绿用于数据趋势和轻量提示，中文标题使用本地宋体回退，操作与正文使用系统字体。没有外部字体、图片或 CDN。

## 页面与主动作

- 新对话：问候、三条具体的提问建议、底部输入框。加号用于引用数据，可以选择回答方式。
- 左侧栏：上方依次为成绩趋势、错题本、考试与计划、时间投入、身心状态、学习日记；下方按日期分组显示历史对话。搜索仅筛选对话历史。底部保留新的对话按钮。
- 数据页面：从侧栏进入完整页面；页首可返回对话或再次展开侧栏；底部固定「聊聊我的……」。点击后回到对话并附上可移除的数据引用。
- 对话：用户消息使用轻底色气泡，AI 回复直接排在画布上。回复包含数据来源入口、可继续提问的建议、复制和有帮助反馈。处理中可停止。

## 关键状态与交互

已实现新对话、侧栏展开／收起、左缘右滑打开／左滑关闭、六个数据页、成绩时间范围切换、引用数据、输入草稿保留、模拟回答、停止生成、历史搜索和无搜索结果、对话本地保存及重新打开、菜单、Esc 退出与侧栏键盘焦点限制。

桌面默认并排展示新对话、展开的侧栏和成绩页面，三屏都可操作。可以切换「单屏体验」，使用状态按钮查看新对话、侧栏、成绩和对话。700 px 以下显示全屏应用，使用动态视口高度及安全区留白。支持 `prefers-reduced-motion`。

## 内容与能力边界

所有成绩、错题、考试、健康、日记和对话均为同一虚构学习场景下的模拟内容；AI 回复为本地预设内容，未连接模型、HealthKit、SwiftData 或真实账户。回答方式仅展示选择状态，不影响真实模型。历史存储在当前浏览器的 localStorage，最多保留 20 条新对话；无法写入存储时，当前页面仍可使用。复制依赖浏览器剪贴板权限，失败时给出可见提示。

原型使用简体中文和本地系统字体。尚未制作深色模式、多语言、真实语音输入、真实模型错误重试，亦未验证真实 iPhone 软键盘。后续 SwiftUI 实现应复用仓库既有 AIChatStyle 积木、LLM 配置及 Repository 数据访问，而不是直接移植此原型的模拟状态。

## 验收

本次为独立、可逆的交互原型，风险按中等分类；影响范围仅为 HTML 及本目录文档。采用 JavaScript 语法检查、浏览器实际渲染与操作检查，不运行 Swift 构建或无关回归测试。目标尺寸包括 402 × 874、375 × 812、320 × 700，以及桌面全景。详细结果见 evidence/verification.json，视觉评审与减法记录见 review.md。
